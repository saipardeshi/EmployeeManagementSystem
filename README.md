# StaffSync — Employee Management System

Simple employee management app. Admins add, edit and delete employees; users can view and search them.

## Tech Stack

Java 17, Spring Boot, MySQL, JWT, HTML/CSS/JavaScript

## Features

- Sign up / sign in (admin and user roles)
- Add, edit, delete employees with photo (admin only)
- Search and filter employees
- Dashboard stats

## Run Locally

1. Create a MySQL database and set `DB_URL`, `DB_USERNAME`, `DB_PASSWORD`, `APP_JWT_SECRET`
2. Run `./mvnw spring-boot:run`
3. Open `http://localhost:8081`
